# Component Selection

| Component | Purpose |
|---|---|
| ESP32 | Main controller |
| Solar panel | Energy collection |
| Li-Po battery | Energy storage |
| OLED display | Information display |
| INA219 | Voltage/current monitoring |
| Qi module | Wireless charging |
| Protection circuit | Battery protection |

## Selection Criteria
- Electrical compatibility
- Physical dimensions
- Power efficiency
- Safety
- Availability
- Cost
