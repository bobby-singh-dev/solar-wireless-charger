# System Architecture

## Project Overview
Development of a portable solar-powered
wireless charging device.

## Main Subsystems

1. Solar energy collection
2. Battery charging and protection
3. Power management
4. Wireless charging
5. Embedded control system
6. Monitoring and display

## Controller
ESP32 microcontroller.

## Monitoring
- Battery voltage
- Charging current
- Battery percentage
- Solar charging status
- Wireless charging status

## Development Status
Research and prototype planning.

- Finalize electrical architecture
- Validate component compatibility
