# Solar Wireless Charger

An experimental solar-powered wireless charging device.

## Project Overview

The objective is to explore a portable charging
solution combining solar energy harvesting,
battery storage and wireless phone charging.

## Planned Components

- ESP32 microcontroller
- Solar panel
- Rechargeable battery
- Battery protection circuit
- Wireless charging module
- OLED display
- Voltage and current monitoring

## Planned Features

- Solar energy monitoring
- Battery percentage display
- Charging status
- Voltage and current monitoring
- Wireless charging
